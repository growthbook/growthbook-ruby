.reduce_payload(payload, attributes: {}, include: {}, exclude: {}, prerequisites: 'keep') ⇒ Hash

Shrink a features payload for a user whose attributes are only partly known, e.g. on a server that bootstraps a client-side SDK. The result evaluates the same as the full payload for anyone who agrees with the known attributes.

Parameters:

  • payload (Hash) —

    A decrypted features payload, as returned by the SDK API (features, experiments, savedGroups, contextualBandits)

  • attributes (Hash) (defaults to: {}) —

    The attributes known for the user

  • include (Hash) (defaults to: {}) —

    Keep only features and experiments that match every filter: projects, tags (arrays, any one value is enough) and customFields (a hash of field to array of values)

  • exclude (Hash) (defaults to: {}) —

    Drop features and experiments that match any filter, with the same keys as include

  • prerequisites ('keep', 'filter') (defaults to: 'keep') —

    With 'keep' (the default), the prerequisites of kept features and experiments are kept even when the filters drop them. With 'filter', only holdouts are.

Returns:

  • (Hash) —

    The reduced payload, with every other key of payload unchanged

def self.reduce_payload(payload, attributes: {}, include: {}, exclude: {}, prerequisites: 'keep')
  Growthbook::PayloadReducer.new(
    Growthbook::Conditions.parse_condition(payload),
    attributes: Growthbook::Conditions.parse_condition(attributes || {}),
    include: payload_filters(include),
    exclude: payload_filters(exclude),
    prerequisites: prerequisites
  ).reduce
end
